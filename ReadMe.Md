# Dog Profile Viewer

A clean **frontend JavaScript project** that fetches and displays a **random dog profile** using a public API.

Built with plain **HTML, CSS, JavaScript, and Axios**, this project focuses on **DOM manipulation, API integration, async/await, and UI consistency**.

---

## Preview

* Random dog image
* Dog breed name
* Breed group
* Bred for
* Life span
* Temperament
* Height and weight
* Fixed-size UI rows with overflow handling

---

## Tech Stack

* HTML5
* CSS3
* JavaScript (Vanilla JS)
* Axios
* FreeAPI Dog API

## Installation

```bash
git clone https://github.com/your-username/Dog-Profile-Viewer.git
cd Dog-Profile-Viewer
```

Then open `index.html` in your browser.

---

## API Endpoint

```text
https://api.freeapi.app/api/v1/public/dogs/dog/random
```
